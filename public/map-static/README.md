# Static map resources

Flightline map textures and glyph stacks retained from the local map fidelity source;
OSM/Protomaps map attribution remains in the map UI. Bathymetry and terrain are the
existing PMTiles inputs. `manifest.json` records file sizes and SHA-256 identities.
Snow support and road density are the already accepted derived masks.
Noto Sans Bold glyph requests use the existing Medium glyphs, as in the Node service.
No Google imagery, Google XYZ source configuration, credentials or caches are included.
